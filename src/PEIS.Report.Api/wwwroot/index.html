🖨️ 客户端打印助手 (PEIS.PrintAgent) 一键安装

为满足医院护士站、医生站“无感知、无弹窗、自动安装”的业务诉求，服务端提供自适应单文件安装包：

  • 全自动安装： 单文件可执行程序（.exe），无需解压 ZIP，下载后直接双击即可完成部署并自动常驻托盘。
  • 免管理员权限： 部署至用户目录（%LOCALAPPDATA%\Programs），在受限域账户或普通权限机器上 100% 成功运行，无 UAC 拦截。
  • 服务端预设配置： 下载时服务端已动态注入当前服务器地址，客户端无需手工配置 ServerUrl。
  • 开机自启动： 自动创建桌面与开始菜单启动项，重启电脑后静默就绪。
