# 受控现场验收清单

本清单用于医院/公司受控现场的最终验收。每项应记录日期、操作者、工作站、配置版本、结果、证据受控位置和异常处置。除非本清单实际完成，不得把自动化测试描述为物理打印验收。

| ID | 验收项 | 执行步骤 | 通过条件 | 结果 |
|---|---|---|---|---|
| F-01 | API 健康检查 | 请求 `/health` | 返回服务正常状态 | [ ] |
| F-02 | 生产安全配置 | 在生产环境确认注册令牌、内部 API 令牌和制品签名密钥均由环境/机密配置提供 | 空令牌启动/注册被拒绝；配置值未写入仓库 | [ ] |
| F-03 | legacy `xmtm` PDF | 用获批只读连接和已授权请求调用 `POST /api/Reports/GetReportByJson` | HTTP 200、`application/pdf`，结果符合已限定的基础路径 | [ ] |
| F-04 | 旧/新页数与尺寸 | 按 `PDF_VISUAL_ACCEPTANCE.md` 运行本地比较 | 页数/尺寸记录完整；异常有处置结论 | [ ] |
| F-05 | 旧/新视觉比较 | 逐页人工复核本地差异图和渲染结果 | 无不可接受的文字、布局、图像、分页差异 | [ ] |
| F-06 | 水印 | 分别测试关闭与启用的配置 | 关闭无变化；启用文本、透明度、角度和位置满足业务要求 | [ ] |
| F-07 | PrintAgent 自动启动 | 用户登录后重启工作站 | 计划任务自动启动；稳定 AgentId 未改变 | [ ] |
| F-08 | Agent 在线与唯一站点 | 检查受保护的代理管理接口；尝试另一 Agent 占用同一 StationId | 正确显示心跳状态；重复在线 StationId 被拒绝 | [ ] |
| F-09 | A4 角色绑定 | 验证 `A4_GUIDE` 映射到安装的本机打印机 | 绑定有效，浏览器不输入物理打印机名称 | [ ] |
| F-10 | 条码角色绑定 | 验证 `BARCODE` 映射到安装的本机打印机 | 绑定有效，浏览器不输入物理打印机名称 | [ ] |
| F-11 | A4 实体打印 | 发起一笔获批测试业务动作 | 单次点击仅产生一次正确 A4 实体输出 | [ ] |
| F-12 | 条码实体打印与扫码 | 发起一笔获批测试业务动作并扫码 | 标签打印正确且扫码业务值一致 | [ ] |
| F-13 | 打印机异常 | 依次模拟离线、卡纸或缺纸（按现场安全规程） | Agent 回执失败可见；不得无限重发或无提示重复打印 | [ ] |
| F-14 | API 重启恢复 | 创建未完成任务，受控重启 API 后查询任务并使用同一幂等键重试 | 状态保留；返回原逻辑任务；不重复打印 | [ ] |
| F-15 | Agent 重启恢复 | 创建未完成任务，受控重启 Agent | Agent 重新注册且不因重连创建新的逻辑任务 | [ ] |
| F-16 | 双击/网络重试 | 对同一业务动作以同一 `IdempotencyKey` 重发 | 返回相同 JobId，实体打印不重复 | [ ] |
| F-17 | 制品访问控制 | 用过期 URL、错误 AgentId 和正确 AgentId 分别请求制品 | 前两者拒绝；正确、未过期、已授权 Agent 可下载 | [ ] |
| F-18 | 制品清理 | 等待/触发保留策略清理 | 过期已完成制品删除；未完成任务制品保留；清理异常不终止 API | [ ] |
| F-19 | 回滚 | 执行批准的服务级/配置级回滚演练 | 旧 PEIS 报表路径可恢复；新 API 与 Agent 可安全停用 | [ ] |

## 现场停止条件

若出现重复实体打印、未授权 PDF 访问、生产环境空令牌仍被接受、模板/字体/条码不可接受，或无法按回滚步骤恢复旧服务，应停止扩大部署、保留证据并执行回滚。
