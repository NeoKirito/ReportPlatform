================================================================================
PEIS.PrintAgent 便携式打印代理使用说明
================================================================================

【目录结构说明】
根目录/
  ├── config.ini           <-- 核心配置文件（双击 [修改配置.cmd] 快捷编辑）
  ├── 启动服务.cmd         <-- 双击启动后台打印代理服务
  ├── 关闭服务.cmd         <-- 双击停止后台打印代理服务
  ├── 查看状态.cmd         <-- 双击查看当前代理运行状态、PID 及最新日志
  ├── 修改配置.cmd         <-- 双击用记事本打开配置文件
  ├── 重置打印机记忆.cmd   <-- 双击清除历史各单据记住的打印机设置
  ├── 使用说明.txt         <-- 本说明文件
  ├── scripts/             <-- 服务管理脚本（无需直接打开）
  │     └── AgentService.ps1
  ├── logs/                <-- 运行日志输出目录（服务启动后自动生成）
  │     ├── agent-YYYY-MM-DD.log  <-- 每日详细业务日志（保留30天，满月自动归档）
  │     └── *.stdout.log / *.stderr.log <-- 启动与标准输出日志
  └── app/                 <-- 核心程序二进制文件及依赖项（内部文件，请勿随意移动）
        └── PEIS.PrintAgent.exe

================================================================================
【客户端极简一键安装（推荐生产现场使用，免配置、免解压）】

方式一（Web 自动探测与一键安装闭环）：
  在浏览器打开系统打印页面（或 http://服务器IP:端口/demo/print.html），
  页面会自动探测本机是否已运行打印助手：
  - 若已运行：直接显示就绪状态；
  - 若未运行：顶部弹出提示，点击【一键下载并自动安装】，下载后直接打开运行。
  * 特性：服务端已自动注入 ServerUrl，无需人工配置，无 UAC 拦截，自动常驻托盘并随开机启动。

方式二（单文件离线安装）：
  直接双击根目录下的 [PEIS-PrintAgent-Setup.exe]，全自动完成组件部署与开机自启动。

================================================================================
【便携服务目录方式（适用于运维调试/后台常驻部署）】

第一步：修改配置
  1. 双击 [修改配置.cmd]；
  2. 修改 ServerUrl 为报表 API 服务地址（例如：http://192.168.0.237:82）；
  3. 如需静默打印：
     - 将 SilentPrint 设置为 true；
     - 将 PrintBackend 设置为 Command（若使用外部命令行打印程序）或 DryRun（测试模式）；
  4. 保存并关闭记事本。

第二步：启动服务
  1. 双击 [启动服务.cmd]；
  2. 窗口显示 "PrintAgent 打印代理已成功启动！" 即代表成功；
  3. 服务将在后台稳定运行，不会占用桌面黑框窗口。

第三步：日常维护
  - 双击 [查看状态.cmd] 可随时查看服务是否正在运行、连接的服务器及最新日志。
  - 双击 [关闭服务.cmd] 可安全退出后台服务。
  - 若更换了物理打印机或想重新选择各体检单对应打印机，双击 [重置打印机记忆.cmd] 即可。
